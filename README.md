# 歡樂小瑪莉 (Little Mary Fruit Slot) - 1990s 經典復古街機水果盤

一款專為現代瀏覽器設計、純純粹粹使用 **HTML5 + CSS3 + 原生 JavaScript** 開發的 1990 年代台灣經典遊藝場「歡樂小瑪莉」水果盤機台遊戲。
**完全無需安裝任何後端伺服器或依賴庫，直接雙擊 `index.html` 即可在任何瀏覽器離線暢玩！**

---

## 🌟 遊戲核心特色與升級亮點

### 1. 投幣回饋優化（無螢幕晃動，純純聽覺與燈號極致反饋）
- **移除全機台晃動**：取消過度晃動視效，維持乾淨穩定的街機視覺體驗。
- **三重擬真音效**：包含硬幣滑入的清脆金屬「卡啷」滑軌聲、落入投幣機體內部的「咕嚕碰撞」聲，以及總分持續遞增時計數音階逐步攀升的「嗶嗶嗶」升調音。
- **視覺燈號回饋**：硬幣進入孔道時，金屬投幣孔旁的綠色 `READY` 指示燈即時強烈閃爍一次，搭配右上角 LED 數字符號閃爍跳分。

---

### 2. 機台右上角「累計投幣金額」LED 顯示幕 (Top-Right Inserted Display)
- **擺放位置**：機台正上方右側，緊鄰金屬投幣孔。
- **顯示內容**：顯示累計投幣實體金額（例：`NT$ 050`），與 `CREDIT` 點數即時同步。
- **動態閃爍與 2 秒過渡**：每次投幣時，標籤切換為「本次投幣 +NT$10」並伴隨紅光 LED 高亮閃動；於最後一次投幣後維持顯示約 2 秒，開跑後自動恢復為「累計投幣 INSERTED」之總金額。
- **樣式風格**：採用 1990 年代經典紅色七段顯示器 (Red 7-Segment LED)，與下方 CREDIT 儀表完全呼應。

---

### 3. 機台左上角「本局中獎金額」LED 顯示幕 (Top-Left Won Prize Display)
- **擺放位置**：機台正上方左側，與右上角投幣顯示幕形成左右完美對稱。
- **顯示內容**：顯示本局獲得之獎金（例：`NT$ 0000`）。
- **即時同步動效**：中獎時數字伴隨歡呼聲階梯跳動累加向上；進行退幣或收分時，數字隨著取幣槽掉落的每枚硬幣同步遞減倒數；若中彩頭獎（BAR 或大滿貫），全顯示框框將爆發彩金警報閃爍！
- **樣式風格**：對稱的紅色 LED 設計，讓玩家抬頭即可一目了然「投幣」與「獲利」的對比。

---

### 4. 全盤面圖示極大化 (Maximum Visibility)
- **水果與特色圖示極限填滿**：BAR、77、星星、西瓜、鈴鐺、木瓜、橘子、蘋果圖標尺寸全面放大，填滿每個邊框格子，外加加粗黑色邊框與高飽和度色彩。
- **大尺寸跑馬燈泡**：外框 24 格配備加大白熾燈泡與外擴光暈，巡航時極具動態衝擊力。
- **LED 數字放大**：所有七段顯示器數字（CREDIT、押分、得分、投幣、中獎）字體加粗加大，作為螢幕最醒目的資訊樞紐。
- **押注按鈕圖示填滿**：下方 8 種水果按鈕的圖案最大化，倍率清晰醒目。
- **維持瑪莉公仔主角**：中央 5×5 區域保留可愛瑪莉與小烏龜卡通插畫，不壓迫周圍水果格空間。

---

### 5. 押注按鈕與 START 按鈕「單排 9 鍵等寬」均勻分佈 (9 Buttons in 1 Row)
- **單一橫排佈局**：8 個水果押注按鈕 + 1 個 START 啟動按鈕，共 **9 個按鈕在同一水平排**排開。
- **等寬均分**：每個按鈕均佔據整排的 $1/9$ 等寬比例，間距一致（使用 CSS 9-Column Grid）。
- **START 獨特配色**：START 位於單排最右側第 9 格，採用專屬的街機熱血烈焰紅漸層與金色邊框，具備呼吸閃爍光暈，清晰防混淆。
- **行動裝置窄螢幕適配**：手機直向時自動微調間距但仍維持單排 9 鍵，按鈕高度加高以保持絕佳點擊手感。
- **COIN OUT 按鈕位置**：退幣按鈕獨立移至下方操作列左側，遠離下注區以防止誤觸。

---

### 6. 專屬台灣拾圓硬幣圖資（真實 10 元硬幣）
- **實體圖資**：採用真實台灣拾圓（NT$10 / 拾圓 10）實體硬幣圖資（`assets/coin10_raw.png`）。
- **投幣飛入動態**：投幣時硬幣自畫面右上方滑入，搭配 3D 沿 Y 軸 720 度翻轉縮小鑽入金屬投幣孔。
- **物理取幣槽與拖曳**：取幣槽內掉落、彈跳與堆疊的硬幣均為高解析度圓形台灣 10 元硬幣，支援點擊收納與直接自托盤拖曳一枚硬幣回投幣孔開分！
- **數值對應**：1 枚硬幣 = 新台幣 10 元 = 10 CREDIT 分數。

---

### 7. 「77」與「BAR」高對比純紅設計 (#E60012)
- **飽和正紅標示**：所有「77」與「BAR」字樣一律採用極度醒目的純紅 `#E60012`。
- **極致對比輪廓**：
  - **BAR**：採用白色底板銘牌 + 粗黑邊框，襯托純紅 BAR 字樣，徹底避免暗紅混淆。
  - **77**：採用純紅字體搭配加厚白色描邊 (`-webkit-text-stroke: 1.5px #fff`) 與立體黑底陰影。
- **涵蓋範圍**：外框 24 格、押注按鈕圖示、倍率表與比倍相關提示。
- **中獎發光動效**：當跑馬燈停在 77 或 BAR 時，純紅字體爆發高亮動態脈衝紅光！

## ⌨️ 鍵盤快捷鍵指南

| 按鍵 | 功能說明 |
| :--- | :--- |
| **空白鍵 (Space)** | 啟動跑馬燈 (START) |
| **C 鍵** | 投幣 (+10 Credit) |
| **1 ~ 8 鍵** | 依序押注：BAR(1), 77(2), 星星(3), 西瓜(4), 鈴鐺(5), 木瓜(6), 橘子(7), 蘋果(8) |
| **Enter 或 T 鍵** | 取得獎金 / 移入總分 (COLLECT) |
| **D 鍵** | 中獎後進入比倍 (DOUBLE-UP) |
| **Z 鍵** | 比倍猜【小】(1~6) |
| **X 鍵** | 比倍猜【大】(7~12) |
| **P 鍵** | COIN OUT 全額退幣吐錢 |

## 📁 專案檔案結構

```
Mary/
│
├── index.html         # 機台主結構、巨型START按鈕、COIN OUT長按按鈕、3D比倍卡牌與Canvas取幣槽
│
├── css/
│   └── style.css      # 1990年代街機外觀、按鈕呼吸閃爍、3D紙牌翻轉、長按進度條、燈光暗淡動效
│
└── js/
    ├── audio.js       # 100% Web Audio API 合成音效（含鼓點、開關按鍵、升調發動、落幣、平手、低沉失敗聲）
    ├── coins.js       # 2D Canvas 物理硬幣碰撞、堆疊計數銘牌、拖曳回投幣孔、收納飛散動效
    └── game.js        # 狀態機、START解鎖規則、COIN OUT全額退幣、比倍加注與1-12翻倍邏輯
```
